# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project exploring customer shopping patterns using **Python (Pandas), SQL (PostgreSQL), and Power BI** — covering the full pipeline from raw data cleaning to SQL-based business analysis and interactive dashboard reporting.

## 📌 Project Overview

This project analyzes a customer shopping behavior dataset (3,900+ records, 18 attributes) to uncover insights around revenue trends, customer segmentation, product performance, and purchasing patterns. The goal was to simulate a real-world analytics workflow: ingesting raw data, cleaning and engineering features in Python, loading it into a relational database, writing business-focused SQL queries, and visualizing the findings in an interactive Power BI dashboard.

## 🧰 Tools & Technologies

- **Python (Pandas)** — data cleaning, feature engineering, and preprocessing
- **PostgreSQL (pgAdmin)** — relational database for querying and analysis
- **SQLAlchemy** — connecting Python to PostgreSQL for data loading
- **Power BI** — interactive dashboard and data visualization
- **Jupyter Notebook** — exploratory data analysis and scripting

## 🔄 Workflow

1. **Data Cleaning (Python)**
   - Loaded raw CSV data and handled missing values (e.g., imputing review ratings by category median)
   - Standardized column names for SQL compatibility
   - Removed redundant columns after validating duplicate information
   - Engineered new features:
     - `age_group` — segmented customers into Young Adult, Adult, Middle-aged, and Senior using quartile binning
     - `purchase_frequency_days` — converted categorical purchase frequency into a numeric day-based value

2. **Database Integration**
   - Loaded the cleaned dataset into a PostgreSQL database using SQLAlchemy and psycopg2

3. **SQL Analysis**
   - Wrote 10+ business-driven SQL queries to answer questions such as:
     - Revenue comparison across gender and age groups
     - Customer segmentation into New, Returning, and Loyal buyers
     - Top-rated and most-discounted products
     - Subscriber vs. non-subscriber spending behavior
     - Top 3 best-selling products within each category
     - Relationship between repeat purchases and subscription status

4. **Dashboard Reporting (Power BI)**
   - Built an interactive dashboard visualizing key metrics: revenue trends, customer segments, product performance, and purchase behavior patterns

## 📊 Key Business Questions Answered

- What is the total revenue generated by male vs. female customers?
- Which customers used a discount but still spent above average?
- What are the top 5 products by average review rating?
- Do subscribed customers spend more than non-subscribers?
- Which products have the highest discount usage rate?
- How are customers distributed across New, Returning, and Loyal segments?
- What is the revenue contribution of each age group?
